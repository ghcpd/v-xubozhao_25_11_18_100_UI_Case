# 🧪 Today's Test: UI Bug Inspection
Category: UI/UX  
Definition: Detect and fix layout issues, visual inconsistencies, or accessibility problems.  

## 🎯 Task Description
You are maintaining a small web interface with known UI issues.  
Your job is to analyze the provided UI bug specification file and:

1. Reconstruct a minimal UI that reflects the described issues.  
2. Identify the root cause of each UI/UX problem.  
3. Propose and implement fixes.  
4. Generate automated scripts to reproduce, test, and verify UI behavior.

The system should generate:
- HTML/CSS/JS (or a minimal framework app) reflecting the problematic UI
- A corrected version with UI fixes
- Test environment setup (e.g., setup.sh)
- UI testing scripts (e.g., run_tests.sh, Playwright/Puppeteer tests)
- Logs or console output showing the UI test results
- Any screenshots required by tests (mocked if necessary)

## Requirements
- Use the provided `ui_bug_spec.json` as the only input file.
- Automatically generate all missing project files.
- Ensure the environment setup is fully reproducible.
- Include automated UI tests that detect layout issues.
- Tests must be runnable via a single script (e.g., `./run_tests.sh`).
- Provide improvement suggestions for UX and accessibility.
- Include screenshots or mock screenshot files.

## Expected Output
- Diagnosed UI issues.
- Fixes for each issue.
- Reproducible environment scripts.
- UI testing scripts + results.
- Screenshot output (can be simulated).
- Final summary report.

## Input File
`ui_bug_spec.json`
